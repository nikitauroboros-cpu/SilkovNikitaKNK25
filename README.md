# SilkovNikitaKNK25

Laboratory work  
Flexbox layout

## Опис

Проєкт містить особисту веб-сторінку, оформлену за допомогою CSS Flexbox.

## Що реалізовано

- flex-header з логотипом, навігацією та кнопкою дії;
- основний контент, який займає всю доступну висоту сторінки;
- сітка карток, що переноситься на новий рядок через `flex-wrap`;
- footer, який залишається внизу сторінки;
- випадкові зображення у картках через сервіс `picsum.photos`.

## Структура проєкту

- `index.html` - стартова сторінка-переадресація на основну HTML-сторінку;
- `pages/index.html` - основна HTML-структура сайту;
- `assets/css/style.css` - усі стилі, Flexbox-розкладка та адаптивність;
- `README.md` - короткий опис лабораторної роботи;
- `.gitignore` - службові файли та папки, які не потрібно відстежувати в Git.

## Як запустити

1. Відкрити `index.html` у браузері.
2. Або одразу відкрити `pages/index.html`.
