Laboratory work №5  
CSS Grid layout + адаптивність

## Опис

Проєкт містить особисту веб-сторінку, де основний макет (сайдбар + контент) і сітка карток реалізовані за допомогою CSS Grid, а також додана адаптивність під планшети та мобільні.

## Що реалізовано

- двоколонковий макет сторінки: `aside` (фільтри) + основний контент через `grid-template-columns`;
- сітка карток через `repeat(auto-fill, minmax(...))` без Flexbox;
- адаптивний медіа-запит `@media (max-width: 768px)` (сайдбар стає над контентом);
- адаптивні стилі для хедера/навігації на вузьких екранах;
- випадкові зображення у картках через сервіс `picsum.photos`.

## Структура проєкту

- `index.html` - стартова сторінка-переадресація на основну HTML-сторінку;
- `pages/index.html` - основна HTML-структура сайту;
- `assets/css/style.css` - усі стилі, CSS Grid-розкладка та адаптивність;
- `README.md` - короткий опис лабораторної роботи;
- `.gitignore` - службові файли та папки, які не потрібно відстежувати в Git.

## Як запустити

1. Відкрити `index.html` у браузері.
2. Або одразу відкрити `pages/index.html`.
