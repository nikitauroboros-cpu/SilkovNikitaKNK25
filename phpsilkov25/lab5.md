# Лабораторна робота №5

**Тема:** Зберігання та виведення статусу (масиви).

**Мета:** створити список завдань у багатовимірному масиві та вивести його через цикл `foreach`.

## Масив завдань

Окремі змінні однієї задачі замінено масивом `$tasks`. Кожне завдання містить `id`, `title`, `priority` та `is_completed`.

```php
$tasks = [
    ['id' => 1, 'title' => 'Виконати лабораторну роботу №5', 'priority' => 'High', 'is_completed' => false],
    ['id' => 2, 'title' => 'Повторити масиви', 'priority' => 'Medium', 'is_completed' => true],
    ['id' => 3, 'title' => 'Перевірити цикл foreach у шаблоні', 'priority' => 'High', 'is_completed' => false],
    ['id' => 4, 'title' => 'Додати скриншот', 'priority' => 'Low', 'is_completed' => true],
    ['id' => 5, 'title' => 'Завантажити звіт на GitHub', 'priority' => 'Medium', 'is_completed' => false],
];
```

## Виведення в HTML

```php
        <ul>
            <?php foreach ($tasks as $task): ?>
                <li class="<?= $task['is_completed'] ? 'task-done' : 'task-pending' ?>">
                    №<?= $task['id'] ?>:
                    <?= htmlspecialchars(formatTitle($task['title']), ENT_QUOTES, 'UTF-8') ?> —
                    Пріоритет: <?= htmlspecialchars($task['priority'], ENT_QUOTES, 'UTF-8') ?> —
                    <?php if ($task['is_completed']): ?>
                        ✔️ Виконано
                    <?php else: ?>
                        🕒 В процесі
                    <?php endif; ?>
                </li>
            <?php endforeach; ?>
        </ul>
```

## Перевірка роботи

Сторінку відкрито за адресою `http://localhost:8080/phpsilkov25/index.php`. У масиві п'ять завдань, тому на сторінці виводяться п'ять елементів списку. Два виконані завдання мають зелений колір, три невиконані — сірий. Біля кожного завдання вказано номер, пріоритет і статус.

Перевірено зміну назви та стану першого завдання в масиві: після оновлення сторінки змінюються текст, статус і CSS-клас. Після перевірки повернуто початкові значення.

Функція `formatTitle()` залишилася з попередньої роботи. Для українських назв у ній використано `mb_strlen()` та `mb_substr()` з кодуванням UTF-8, щоб рахувати символи та не пошкоджувати літери під час обрізання. Короткі назви виводяться повністю, довгі — із `...`.

## Контрольні запитання

**1. Чим відрізняються індексовані та асоціативні масиви в PHP?**

В індексованому масиві елементи зазвичай мають числові ключі, які автоматично починаються з нуля. В асоціативному масиві ключам надають змістовні назви. У PHP обидва варіанти є одним типом `array`; ключі можуть бути цілими числами або рядками.

```php
$priorities = ['High', 'Medium', 'Low'];
echo $priorities[0]; // High

$task = ['title' => 'Повторити масиви', 'is_completed' => true];
echo $task['title']; // Повторити масиви
```

У роботі зовнішній масив `$tasks` має числові ключі, а кожен його елемент — асоціативний масив із полями окремого завдання.

**2. Які компоненти містить foreach і чим він зручніший за for для масивів?**

У записі `foreach ($tasks as $task)` вказано масив для перебору, слово `as` і змінну, яка на кожній ітерації отримує значення поточного елемента. За потреби можна отримати також ключ: `foreach ($tasks as $key => $task)`.

`foreach` сам переходить між елементами. Не потрібно створювати лічильник, перевіряти довжину масиву або вручну збільшувати індекс. Він працює і з рядковими ключами, і з числовими ключами з пропусками. Цикл `for` залишається корисним, коли потрібно керувати числовим кроком або діапазоном, але для звичайного перебору масиву `foreach` простіший.

**3. Що буде при зверненні до ключа, якого немає в масиві?**

У PHP 8 звернення до `$task['deadline']`, якщо такого ключа немає, викликає попередження `Undefined array key`, а результатом читання буде `null`. Сам цикл `foreach` не створює відсутні поля. Видимість попередження на сторінці залежить від налаштувань показу помилок.

Для необов'язкового поля можна задати запасне значення:

```php
$deadline = $task['deadline'] ?? 'Не вказано';
```

Оператор `??` використає запасне значення, якщо ключ відсутній або його значення дорівнює `null`. Якщо потрібно розрізняти ці випадки, застосовують `array_key_exists()`.

**4. Навіщо використовувати endforeach замість фігурної дужки в HTML-шаблоні?**

Альтернативний синтаксис дозволяє писати HTML між відкриттям і завершенням циклу:

```php
<?php foreach ($tasks as $task): ?>
    <li><?= htmlspecialchars($task['title'], ENT_QUOTES, 'UTF-8') ?></li>
<?php endforeach; ?>
```

Так розмітку не потрібно складати в рядки для `echo`, а `endforeach;` явно показує завершення циклу. Поведінка та сама, що й у варіанті з фігурними дужками; змінюється лише запис коду.

**5. Наведіть приклади функцій для роботи з масивами.**

- `count($tasks)` повертає кількість елементів. У цій роботі результат — 5.
- `array_column($tasks, 'title')` створює масив зі значень поля `title` усіх завдань.
- `array_filter($tasks, fn($task) => $task['is_completed'])` відбирає виконані завдання. Ключі вихідного масиву зберігаються.
- `sort($numbers)` сортує значення масиву за зростанням і заново нумерує ключі. Функція змінює переданий масив.

```php
$numbers = [3, 1, 2];
sort($numbers); // $numbers тепер [1, 2, 3]
```

## Висновок

Список завдань збережено в багатовимірному масиві. Цикл `foreach` формує HTML для кожного запису, а стан завдання визначає його статус і колір. Для додавання нового завдання достатньо додати елемент до масиву.
