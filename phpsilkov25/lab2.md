# Лабораторна робота №2

**Тема:** Виведення динамічного контенту.

**Мета:** створити HTML-сторінку та вивести в ній значення PHP-змінних.

## Хід роботи

У файлі `index.php` замінено Hello World і `phpinfo()` на базову сторінку Task Manager. Додано HTML-каркас, блоки `header` та `main`.

На початку файлу оголошено дві рядкові змінні й одну цілочисельну:

```php
<?php
$appName = 'Task Manager';
$taskTitle = 'Вивчити основи PHP';
$taskTimeEstimate = 2;
?>
```

Значення виводяться в HTML через короткий запис `<?= ?>`:

```html
<header>
    <h1><?= $appName ?></h1>
</header>
<main>
    <h2>Моє завдання</h2>
    <ul>
        <li>Завдання: <?= $taskTitle ?></li>
        <li>Очікуваний час: <?= $taskTimeEstimate ?> год.</li>
    </ul>
</main>
```

## Запуск

З кореня репозиторію на macOS із XAMPP:

```sh
/Applications/XAMPP/xamppfiles/bin/php -S localhost:8080 -t .
```

Якщо PHP додано до PATH, достатньо `php -S localhost:8080 -t .`.

Адреса сторінки: `http://localhost:8080/phpsilkov25/index.php`.
