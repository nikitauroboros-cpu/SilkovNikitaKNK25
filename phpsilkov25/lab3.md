# Лабораторна робота №3

**Тема:** Робота з умовами в розмітці.

**Мета:** змінювати статус і оформлення завдання залежно від значення логічної змінної PHP.

## Хід роботи

У `index.php` додано змінну стану завдання:

```php
$isCompleted = false;
```

У `<head>` додано стилі для виконаного завдання та завдання в процесі:

```html
<style>
    .task-done { color: green; }
    .task-pending { color: gray; }
</style>
```

В елементі списку використано тернарний оператор для вибору CSS-класу та альтернативний синтаксис `if / else / endif` для виведення статусу:

```php
<li class="<?= $isCompleted ? 'task-done' : 'task-pending' ?>">
    Завдання: <?= $taskTitle ?> —
    <?php if ($isCompleted): ?>
        ✔️ Виконано
    <?php else: ?>
        🕒 В процесі
    <?php endif; ?>
</li>
```

## Перевірка

Сторінка запускається через локальний PHP-сервер за адресою `http://localhost:8080/phpsilkov25/index.php`.

| Значення `$isCompleted` | Статус | CSS-клас | Колір |
|---|---|---|---|
| `false` | 🕒 В процесі | `task-pending` | Сірий |
| `true` | ✔️ Виконано | `task-done` | Зелений |

Перевірено обидва значення зі зміною змінної у PHP-коді та оновленням сторінки. У підсумковому файлі залишено `$isCompleted = false;`.

## Висновок

Статус завдання виводиться за допомогою умовного оператора, а CSS-клас визначається тернарним оператором. Зміна однієї логічної змінної змінює текст статусу й колір завдання.
