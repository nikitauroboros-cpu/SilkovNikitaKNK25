# Лабораторна робота №3

**Тема:** Робота з умовами в розмітці.

**Мета:** змінювати статус і оформлення завдання залежно від значення логічної змінної PHP.

## Хід роботи

У `index.php` додано змінну стану завдання:

```php
$isCompleted = false;
```

У `<head>` додано стилі для виконаного завдання та завдання в процесі:

```html
<style>
    .task-done { color: green; }
    .task-pending { color: gray; }
</style>
```

В елементі списку використано тернарний оператор для вибору CSS-класу та альтернативний синтаксис `if / else / endif` для виведення статусу:

```php
<li class="<?= $isCompleted ? 'task-done' : 'task-pending' ?>">
    Завдання: <?= $taskTitle ?> —
    <?php if ($isCompleted): ?>
        ✔️ Виконано
    <?php else: ?>
        🕒 В процесі
    <?php endif; ?>
</li>
```

## Перевірка

Сторінка запускається через локальний PHP-сервер за адресою `http://localhost:8080/phpsilkov25/index.php`.

| Значення `$isCompleted` | Статус | CSS-клас | Колір |
|---|---|---|---|
| `false` | 🕒 В процесі | `task-pending` | Сірий |
| `true` | ✔️ Виконано | `task-done` | Зелений |

Перевірено обидва значення зі зміною змінної у PHP-коді та оновленням сторінки. У підсумковому файлі залишено `$isCompleted = false;`.

## Висновок

Статус завдання виводиться за допомогою умовного оператора, а CSS-клас визначається тернарним оператором. Зміна однієї логічної змінної змінює текст статусу й колір завдання.


## Контрольні запитання

**1. Які оператори порівняння існують у PHP?**

`==` перевіряє рівність значень із можливим перетворенням типів, `===` — однакові значення і типи, `!=` або `<>` — нерівність, `!==` — відмінність значення або типу. Також є `>`, `<`, `>=`, `<=`. Ці оператори повертають `true` або `false`. Оператор `<=>` повертає `-1`, `0` або `1` залежно від результату порівняння.

**2. У чому різниця між `===` та `==`?**

`==` порівнює значення, за потреби перетворюючи типи. `===` перевіряє і значення, і тип без приведення типів. Наприклад:

```php
var_dump(5 == "5");  // bool(true)
var_dump(5 === "5"); // bool(false)
var_dump(5 === 5);   // bool(true)
```

Число 5 і числовий рядок "5" рівні за значенням, але мають різні типи. Для перевірки значення разом із типом застосовують `===`. Оператор присвоєння — `=`, а `==` є оператором порівняння.

**3. Для чого потрібен альтернативний синтаксис керуючих конструкцій під час роботи з HTML?**

Він дозволяє розміщувати звичайний HTML між PHP-блоками й чітко позначати межі умови. Замість фігурних дужок використовуються двокрапка та `endif;`. У шаблонах це зручніше, ніж збирати великі HTML-фрагменти в рядки для `echo`. Логіка умови залишається такою самою, як у записі з дужками.

```php
<?php if ($isCompleted): ?>
    <span>Виконано</span>
<?php else: ?>
    <span>В процесі</span>
<?php endif; ?>
```

**4. Що таке тернарний оператор і коли його використання є недоцільним?**

Тернарний оператор вибирає одне з двох значень залежно від умови. Синтаксис: `умова ? значення_якщо_true : значення_якщо_false`. У роботі він визначає CSS-клас:

```php
$taskClass = $isCompleted ? "task-done" : "task-pending";
```

Він зручний для короткого вибору значення. Для великих блоків HTML, кількох дій у кожній гілці чи складних вкладених перевірок краще використовувати `if / elseif / else`: такий код легше читати й змінювати.

**5. Які значення PHP приводить до `false` в умові `if`?**

До `false` приводяться: саме `false`, ціле число `0`, дійсні числа `0.0` і `-0.0`, порожній рядок `""`, рядок `"0"`, порожній масив `[]` та `null`. Читання неініціалізованої змінної також дає `null`, але супроводжується попередженням, тому змінні слід оголошувати заздалегідь.

Інші звичайні значення істинні: наприклад, `-1`, рядки `"false"`, `"0.0"` і рядок із пробілом, а також непорожні масиви. Звичайні об’єкти теж істинні; окремі внутрішні класи можуть мати спеціальні правила, наприклад деякі порожні об’єкти SimpleXML.

```php
var_dump((bool) "0");     // bool(false)
var_dump((bool) "false"); // bool(true)
var_dump((bool) []);      // bool(false)
var_dump((bool) [0]);     // bool(true)
```
