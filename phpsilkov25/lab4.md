# Лабораторна робота №4

**Тема:** Форматування даних власними функціями.

**Мета:** створити функції для скорочення назви завдання та виведення привітання залежно від часу.

## Створені функції

```php
date_default_timezone_set('Europe/Kyiv');

function formatTitle($text, $maxLength = 20)
{
    if (strlen($text) > $maxLength) {
        return substr($text, 0, $maxLength) . '...';
    }

    return $text;
}

function getCurrentGreeting()
{
    $hour = (int) date('H');

    if ($hour >= 6 && $hour < 12) {
        return 'Доброго ранку';
    } elseif ($hour >= 12 && $hour < 18) {
        return 'Добрий день';
    } elseif ($hour >= 18) {
        return 'Добрий вечір';
    }

    return 'Доброї ночі';
}
```

## Використання в HTML

```php
<header>
    <h1><?= $appName ?></h1>
    <p><?= getCurrentGreeting() ?>!</p>
</header>
```

Назва завдання в елементі списку виводиться як `<?= formatTitle($taskTitle) ?>`. Для перевірки задано `$taskTitle = 'Learn PHP functions and text formatting';`. Результат: `Learn PHP functions ...`.

Тестову назву записано латиницею, оскільки вказані в завданні `strlen()` і `substr()` працюють із байтами. Для українських назв у UTF-8 слід використовувати `mb_strlen()` та `mb_substr()`, щоб не розрізати багатобайтовий символ.

## Перевірка

Сторінку відкрито через локальний PHP-сервер за адресою `http://localhost:8080/phpsilkov25/index.php`. Часовий пояс — `Europe/Kyiv`.

Перевірено: короткий текст і текст довжиною рівно 20 символів не змінюються; довший текст обрізається до 20 символів із додаванням `...`; власне значення другого аргументу змінює межу обрізання. Порожній рядок залишається порожнім.

Привітання залежить від години: 00–05 — «Доброї ночі», 06–11 — «Доброго ранку», 12–17 — «Добрий день», 18–23 — «Добрий вечір». Перевірено межі цих проміжків.

## Контрольні запитання

**1. Поясніть принцип DRY та як власні функції допомагають його дотримуватись.**

DRY означає Don't Repeat Yourself — «не повторюй себе». Однакову логіку не слід копіювати в різні частини програми: її можна оформити як функцію та викликати в потрібних місцях. Наприклад, `formatTitle()` дозволяє однаково скорочувати назви різних завдань. Якщо правило форматування зміниться, достатньо змінити одну функцію, а не кожне місце виведення.

**2. Що таке аргументи функції та параметри за замовчуванням?**

Параметри — це змінні в оголошенні функції, а аргументи — конкретні значення, передані під час виклику. У `formatTitle($text, $maxLength = 20)` параметр `$text` обов'язковий, а `$maxLength` має значення за замовчуванням 20. Виклик `formatTitle($taskTitle)` використовує межу 20, а `formatTitle($taskTitle, 10)` передає власну межу 10. Так функція працює з різними даними без дублювання коду.

**3. Що буде в `$x`, якщо функція не містить `return`?**

Якщо звичайна функція завершується без `return`, її результатом є `null`. Навіть якщо всередині використовується `echo`, це лише виведення, а не повернення значення:

```php
function myFunc()
{
    echo 'Hello';
}

$x = myFunc(); // виведе Hello
var_dump($x); // NULL
```

Щоб присвоїти результат змінній, потрібно повернути його, наприклад `return 'Hello';`.

**4. Що таке область видимості змінної? Чи доступна зовнішня `$taskTitle` у функції без `global`?**

Область видимості визначає, де змінна доступна в коді. Змінні всередині звичайної функції локальні; змінна `$taskTitle`, оголошена поза функцією, автоматично всередині не доступна. У цій роботі її значення передається аргументом: `formatTitle($taskTitle)`, а функція працює з локальним параметром `$text`. Це робить її незалежною від назви зовнішньої змінної. Доступ до глобальної змінної також можливий через `global` або масив `$GLOBALS`, а замикання можуть захоплювати змінні через `use`, але для цієї задачі достатньо параметра.

**5. Для чого призначена `substr()` і які аргументи вона приймає?**

`substr($string, $offset, $length)` повертає частину рядка. Перший аргумент — початковий рядок, другий — позиція початку (нумерація з нуля), третій — необов'язкова довжина. Без третього аргументу повертається решта рядка до кінця. Від'ємний початок рахується від кінця; від'ємна довжина виключає відповідну кількість байтів у кінці.

```php
substr('Hello World', 0, 5); // 'Hello'
substr('Hello World', 6);    // 'World'
substr('Hello World', -5);   // 'World'
```

Функція працює з байтами, тому для коректного обрізання тексту з українськими літерами в UTF-8 застосовують `mb_substr($text, 0, $length, 'UTF-8')`.

## Висновок

Створено дві функції з поверненням результату через `return`. Вони використовуються безпосередньо у HTML: одна скорочує назву завдання, інша формує привітання відповідно до поточного часу.
