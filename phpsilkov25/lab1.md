# Лабораторна робота №1

**Тема:** Встановлення сервера та Hello World.

**Мета:** налаштувати локальний запуск PHP і перевірити виконання першої програми у браузері.

## Хід роботи

Для роботи використано PHP 8.2.4 зі встановленого XAMPP та браузер Safari. Проєкт розміщено в папці `phpsilkov25` у спільному навчальному репозиторії. Для запуску використано вбудований HTTP-сервер PHP — альтернативу Apache для локальної перевірки.

Створено файл `index.php`:

```php
<?php
echo "<h1>Hello World! Це моя перша PHP-програма.</h1>";
phpinfo();
```

Для повторного запуску на macOS із XAMPP потрібно відкрити термінал у корені репозиторію й виконати:

```sh
/Applications/XAMPP/xamppfiles/bin/php -S localhost:8080 -t .
```

Якщо PHP вже доступний у PATH:

```sh
php -S localhost:8080 -t .
```

Після цього відкрити `http://localhost:8080/phpsilkov25/index.php`. Сервер має залишатися запущеним; зупинка — Ctrl+C.

У браузері перевірено виведення заголовка Hello World та таблиці `phpinfo()` з версією PHP 8.2.4. [Перша сторінка результату, збережена з браузера у PDF](result.pdf). PDF містить адресу localhost; це друк сторінки, а не скриншот вікна браузера.

GitHub зберігає вихідний код і звіт. GitHub Pages не виконує PHP, тому програму потрібно запускати через локальний PHP-сервер.

## Контрольні запитання

**1. Для чого потрібен вебсервер Apache?**

Apache приймає HTTP-запити від браузера і повертає відповіді: HTML-сторінки, зображення та інші ресурси. За відповідного налаштування він передає PHP-код інтерпретатору, а браузеру надсилає результат виконання. У цій роботі запити обробляв вбудований сервер PHP.

**2. Яке розширення мають файли PHP?**

Зазвичай `.php`, наприклад `index.php`. Такий файл може містити PHP-код між тегами `<?php ... ?>` і HTML. Якщо файл містить лише PHP, завершальний тег можна опустити.

**3. Чому потрібно відкривати файл через localhost, а не подвійним клацанням?**

Через `localhost` браузер звертається до сервера на цьому комп'ютері. Сервер запускає PHP і повертає готовий результат. Подвійне клацання відкриває файл як локальний документ; браузер самостійно PHP не виконує. Номер `8080` в адресі означає порт запущеного сервера.

**4. Для чого використовується echo?**

`echo` виводить текст у відповідь програми. У прикладі він виводить HTML-заголовок `<h1>`, який браузер показує як заголовок сторінки. `echo` — мовна конструкція PHP.

**5. Що показує phpinfo() і навіщо це потрібно?**

`phpinfo()` показує версію PHP, конфігурацію, шлях до `php.ini`, доступні розширення, спосіб взаємодії із сервером та інші параметри середовища. Це допомагає перевірити встановлення PHP і знайти причини проблем із налаштуваннями чи модулями.

## Висновок

Створено і запущено першу PHP-програму. Перевірено виведення HTML через `echo` та перегляд параметрів PHP за допомогою `phpinfo()`.
